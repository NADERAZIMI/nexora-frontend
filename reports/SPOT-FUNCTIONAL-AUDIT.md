# NEXORA Spot Trading — Phase 02A Functional Audit

Completed: 2026-10-20, Asia/Tehran. Initial inspection and browser checks were completed before the interruption; this report resumes those findings. Audited revision: `403c4d333ac23cd1cb11a5130292086ba79a2b6c`.

## Scope, sources and evidence rules

**Audit only.** No application code, CSS, asset, logo, layout, backend, reference HTML, or UI was modified. No new page, implementation phase, commit or push was started. Only this report and ignored diagnostic files were written; browser probes used disposable runtime state.

The design authority is the local [nexora-spot.html](../nexora-spot.html), not screenshots. Implementation sources reviewed: [main.tsx](../src/main.tsx), [snapshot.html](../src/snapshot.html), [reference.css](../src/reference.css), [palette.css](../src/palette.css), [fidelity.css](../src/fidelity.css), [prototype.css](../src/prototype.css), and [package.json](../package.json). The raw reference is intentionally excluded from Git; its link works in this workspace.

Evidence is distinguished throughout:

- **Observed:** DOM/CSS inspection, handler inspection, or an actual local browser action.
- **HTML-supported intent:** an anchor, label, ARIA state or named wrapper establishes an affordance. This does not establish the contents of a missing menu or the behavior of the live original exchange.
- **Proposed:** recommended future work, subject to a confirmed contract and a new implementation request.

The saved reference contains 129 scripts: 128 empty elements and one `application/ld+json` metadata block. No inline `on…` event attributes were found. It preserves the page's captured presentation, not its original application handlers, API contracts or WebSocket messages. Most inactive panels are absent; Limit has an empty hidden panel. Selected tabpanel shells are also empty while the actual visible content is elsewhere in the DOM.

The reference shows TRX/USDT; the current prototype shows static BTC/USDT. The previous explicit input-fix request deliberately made both Price and Total editable numeric fields. The original Market Price field is disabled. This intentional difference is not classified as an accidental regression.

## Classification

| Status | Meaning |
| --- | --- |
| Working | The specifically described local behavior works. It does not imply a connected trading service. |
| Partially working | Some rendering/state behavior works, but the feature is incomplete. |
| Non-functional | An identifiable control does not perform its named action. A placeholder notice is not that action. |
| Backend-dependent | Real market/account behavior requires a service/data contract; current content is static or a placeholder. |
| Not verifiable from the saved HTML | The exact original action, missing menu, target content or contract is unavailable. Current observations are still documented. |

Priorities: **P0** = resolve before production/live execution or live-service claims; **P1** = core Spot local interaction foundation; **P2** = supporting work or a missing-reference gate; **P3** = lower-priority convenience. These are recommendations, not authorization.

Dependency abbreviations used in the inventory:

- **Local:** no backend/API/WebSocket is required for the described UI behavior.
- **Market:** fixtures can be local; genuine current market data requires an approved API/feed. The HTML does not mandate WebSockets or a particular transport.
- **Account:** genuine balances, funding, orders/history or account actions require an authenticated backend/API. Streaming is optional until an approved contract specifies it.
- **Link:** normal navigation needs no application backend; the external destination/service is unverified and requires an approved NEXORA URL policy.
- **Unknown:** the archive is insufficient to determine the integration requirement. Do not invent a service or menu contract.

## Findings at a glance

The frontend remains a static visual prototype with a small delegated event layer. Numeric input entry, local notices and limited side/percentage state work. Most navigation and inactive-tab clicks are intercepted with notices; many div/span/SVG pointer controls have no handler at all.

The chart consists of canvas background images, not a functioning chart engine. There is no market/account feed, trading WebSocket, live indicator computation, drawing model, account session, funding workflow or real order lifecycle. The only socket observed was the local Vite HMR connection.

Buy/Sell switches highlighting and a `data-local-side` attribute on the Buy wrapper; it does not render an independent Sell form. Slider click/keyboard updates work, but dragging does not update continuously. The checkbox changes its native checked state without changing its custom checkmark or filtering data.

Original-venue links remain, including a TRX conversion URL on the current BTC page. Static fees, `Holdings(2)` and `Network Normal` are captured content, not evidence of account state or a real service connection.

## Detailed verified findings and uncertainty

### Local entry, drag and checkbox behavior

Existing input checks passed decimal typing/replacement and persistence across opening/closing notices. Both input boxes retain their original measured geometry, wrapper padding `8px 12px` and wrapper radius `8px`. Computed input fill is `#101014`, text `#F4F6FA` and placeholder `#929AAA`; main backgrounds are `#080808` and inspected secondary panels `#101014`. This does not validate financial calculations or order execution.

Slider probe: midpoint click produced `aria-valuenow=50` and Total `0`. End then ArrowLeft produced `99`. Dragging toward 25% left the value at `99` during movement; release committed `25`. The zero Total write is explicit in `setPercent()` for the saved zero balance, rather than an unexplained overwrite during typing. Active mark/dot classes are never synchronized.

Checkbox probe: native checked became true while wrapper classes stayed `ant-checkbox-v2` / `ant-checkbox-v2-wrapper`. The custom `::after` checkmark stayed at opacity 0 and zero-scale transform. There are no nonempty order rows to verify filtering, and no filtering/checkbox-reading handler exists in `main.tsx`.

Negative Price/Total values pass browser validity because no min/required constraints exist. The reference cannot establish desired minimums, tick precision, affordability, fee/rounding rules or a Price/Total calculation. Obtain a trading contract before implementing such rules. The captured main action says Deposit; there is no evidence of an enabled original order-submit state.

### Keyboard and hit-target limits

Numeric inputs use native keyboard entry. The slider implements ArrowLeft/Right/Home/End. Buy/Sell and many icons/dropdowns are pointer div/span/SVG targets without native button semantics. Focused Limit role=tab did not activate on Enter. Some nested anchors can synthesize clicks on Enter, but that does not establish complete tab keyboard behavior. Spot DCA is a focusable role=button without corresponding handlers.

Profile SVG activation timed out. DOM hit testing found its point covered by a score image; no profile handler was found. Treat profile interaction as unverified, not as a functioning account menu. Do not redesign hit regions as part of this audit.

### Inconsistent captured state

Current labels/chart show BTC/USDT while hidden `data-symbol=TRX_USDT` and the conversion href still identify TRX. Leverage text changed from source 1X-200X to current 1X-500X. Fixed rates, counts, prices and percentages are not derived from a selected-instrument/account state model. These observations do not establish any real leverage product, balance or fee entitlement.

The chart's original tooltip/legend DOM is hidden, while current visible labels are raster content. A future chart engine must not treat stale hidden TRX readouts as a BTC data source. No full historical numeric candle series is retained in the archive.

### Missing states are discovery gates

Inactive Info, Trading Data, Market Trades, Grid, TP/SL, histories, holdings and strategies contents cannot be reconstructed faithfully from this file. Limit is an empty hidden shell. Pair-selector results, additional timeframe options, indicator/drawing menus, fee details, support drawers, validation messages and account flows are not captured. No populated orders/cancel/edit/pagination state exists. Do not add guessed fields, table columns, menus, strategies or order types and call them original behavior.

Literal anchor destinations prove navigation attributes, not current destination availability or suitability under NEXORA branding. External destinations were not contacted. Reference body attributes reflecting a captured logged-in state are not evidence of an active current session.
